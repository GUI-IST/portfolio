Test Engineer Intern, Test & Laboratory team

SiliconGate → Celera Semiconductor

Celera Semiconductor bought SiliconGate. I was at SiliconGate from Aug 2025 to Jun 2026 and continued with the same team under Celera Semiconductor from Jun to Jul 2026.

Summary: I validated and characterized power-management semiconductor IP on silicon. I built and automated test setups, made hardware measurements, soldered and assembled circuits, and wrote code to control and analyze the test systems.

Show full technical detail
  • About 1,500 hours of hands-on lab work.
  • Characterization of power-management IP: startup sequencing, line transients, AC and DC measurements, and temperature-dependent tests with a thermal stream system.
  • Powering fragile engineering samples safely: sequencing supplies to each block of the IC through relays and programmable sources, sourcing and measuring with Keithley SourceMeter units.
  • Trimming on-chip clock, temperature, voltage and current settings through JTAG/IJTAG, and controlling electronic and programmable loads during measurements.
  • Python instrument drivers: I wrote drivers for two arbitrary waveform generators, working from their programming manuals (SCPI over GPIB with PyVISA). They handle binary waveform upload, multi-segment sequences with trigger and marker logic, hardware limit checks and input validation, and include a GUI instrument panel. Both drivers are integrated into the company's automated test framework.
  • Adapting the team's existing Python processing and plotting code (pandas, Matplotlib) to each new instrument and sample, so results stayed organized and consistent.
  • Hand-soldering and assembling test circuits, including small SMD components under a microscope.
  • Git used daily for all driver and test code.
  • Equipment: Keithley SourceMeters (SMU), LCR meter, laboratory power amplifiers, oscilloscopes and current probes, arbitrary waveform and function generators, frequency counter, signal source analyzer, programmable DC power supplies, electronic and programmable loads, battery chargers, relays, JTAG/IJTAG, thermal stream system.
